# Azeroth Pinpoint

A static five-round daily map guessing game for World of Warcraft: Forever. See the [status](docs/STATUS.md), [build graph](docs/BUILD_GRAPH.md), [acceptance tests](docs/ACCEPTANCE.md), and [source ledger](DATA_PROVENANCE.md).

Requires Node.js 20.19 or newer and npm.

```sh
npm ci
npm run dev
```

For a local production preview, run `npm run build` and `npm run preview`.
